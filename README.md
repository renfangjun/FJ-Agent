## 📖 项目简介

**FJ-Agent** 是一个以"恋爱大师"为定位的 AI 超级智能体（Super Agent），旨在为用户提供情感陪伴、聊天互动与恋爱建议。
本仓库目前处于早期阶段，更多能力仍在持续完善中。
